# Mengjie Lu - data science portfolio
Static portfolio for the Iris exploratory analysis.
Project: https://github.com/origami00025-lab/data-science-project
Expected website after publishing (not evidence of deployment): https://origami00025-lab.github.io/data-science-portfolio/

## GitHub Pages setup
Settings > Pages > Build and deployment > Deploy from a branch > main > / (root) > Save.
The styled root entry is index.html. The root index.md also supplies the Markdown entry requested in the course instructions. No build tool or API key is required. Images use relative assets/ paths to work on a repository Pages site.

## Local preview
Open index.html in a browser, or run python -m http.server 8000 and visit http://localhost:8000.
